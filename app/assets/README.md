# assets

Small SVG icons referenced by the stylesheet in `app/theme.py`:

- `check.svg` – white tick drawn inside a ticked checkbox
- `chevron-down.svg` – arrow on drop-down boxes, date pickers and number boxes
- `chevron-up.svg` – up arrow on number boxes

These are the only image files the UI needs. When the app is packaged with
PyInstaller, this folder must be included (see README.md, "Packaging").
